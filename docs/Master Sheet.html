Components

Families are named after the shape of what they hold, not the domain they serve. workflow/ is the one exception — the approval layer that knows what a request is. Variants are prop-chosen forms; states are situational. Everything in a row is read from that export's own props interface and its own doc comment, so a shared file never lends one export another's props; a dash means it genuinely has none.

Bundle contract

Consuming AgniUI

  1. Link the stylesheet: <link rel="stylesheet" href="styles.css">
  2. Load Phosphor (regular · bold · fill) from CDN.
  3. Load _ds_bundle.js and destructure: const { Button, AppShell } = window.AgniUIAgnikulERPDesignSystem_153d9e
  4. Theme with data-theme="dark", density with data-density, size with data-scale.

Generated files — never hand-edit

  • _ds_bundle.js — all 121 named exports (116 components + 5 helper objects and catalogs), one flat namespace.
  • _ds_manifest.json — components · cards · tokens · templates. The source of this sheet.
  • _adherence.oxlintrc.json — lint rules for consuming projects.

Folder moves never change the namespace: components are always reached flat off the bundle, so re-organising sources cannot break a consumer.

Patterns

Fixed compositions, documented on guidelines/rules/patterns.card.html.

PatternComposition
Page anatomyShellHeader → NavRail → PageTitleBar → (QuickStats) → PageControls → content view → ShellFooter, with the WorkspacePane at the right edge. The title bar owns the view switcher whenever both it and PageControls are on screen.
The five content viewsOne record set, five renderings, one filter contract: DataTable · RecordCard grid · KanbanBoard · GanttTimeline · Calendar. All take loading · empty · error with fixed precedence error → loading → empty → content.
Record lifecycleCreate (Sheet + RequestForm) → Review & submit (ReviewSubmitModal · DiscardConfirmModal) → Confirm (SubmitConfirmModal) → Approve/reject (RequestDetailModal · ApprovalStepper · AuditTrail · BulkActionConfirm) → Track (StatusChip · RecordCard preset="task"). Bulk entry substitutes ImportRecordsModal for steps 1–3.
Record-detail pageLeft: identity + DetailList. Right: header (back · StatusChip · DropdownMenu) → Tabs → StatCard strip → DetailSection ×N → AttachmentRow ×N. Read-only by default; editing is a hand-off to the form that owns those fields.
