Part A — Foundations

A1–A3 · Token layer, tiers, naming

EXISTS — every component reads CSS custom properties (Tailwind utilities resolving to var(--token), or raw var() in a few exempted files); no hardcoded hex found in component logic.

3 tiers, all EXISTS: primitive (brand.css, 10 tokens) → semantic (colors.css, ~235 tokens, light+dark paired) → component (components.css, 90 tokens). Non-tiered token files: typography (21), spacing/density/z-index/breakpoints (78), layout/sizing (21), elevation+motion (13), charts (38), states/a11y (15). System total: 727 tokens.

Naming convention: --<domain>-<role>[-<modifier>], kebab-case. Verbatim examples: --agni-green-600, --surface-brand-soft, --button-primary-bg-hover, --text-tertiary, --z-dropdown, --density-control-h, --focus-ring-error, --chart-1-soft, --tone-done-fg, --border-control.

Part D — Export and code

D1–D2 · What exports today

The compiled runtime bundle _ds_bundle.js (plain JS, no build step) + _ds_manifest.json, loaded via <script src>. templates/repo-scaffold is an unrun npm-package scaffold — no evidence it has been built or published. No PNG/PDF/Figma export exists. Output = React components + a CSS token file; no static HTML/CSS-only or design-file export.

D3–D4 · Styling approach, evidence

Tailwind v4 utilities over the CSS-custom-property layer; a named set of exemptions (charts, Loading's skeleton geometry, Cluster/Stack) stay inline-style by rule. No CSS Modules, no CSS-in-JS.

// components/core/Button.tsx (verbatim)
export function Button({ items = null, iconOnly = false, round = false, active = false, ...p }: any) {
  if (items && items.length) return <SplitButton items={items} {...p} />;
  if (iconOnly || round || active) {
    const cat = p.variant || p.category || "ghost";
    const v = cat === "solid" || cat === "outline" || cat === "ghost" ? cat
      : cat === "primary" ? "solid" : cat === "secondary" ? "outline" : "ghost";
    return (
      <IconButton icon={p.icon} variant={v} size={p.size} round={round} active={active}
        disabled={p.disabled} title={p.title} tooltipSide={p.tooltipSide}
        onClick={p.onClick} style={p.style} />
    );
  }
  return <ButtonBase {...p} />;
}
