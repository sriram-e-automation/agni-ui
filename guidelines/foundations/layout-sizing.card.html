Sizing & constraints

Every element declares how it sizes on each axis — hug its content, fill its container, or stay fixed — plus optional min / max clamps. Elements that float over a surface (badges, close buttons, today-lines) use constraints: pinned edges inside a position:relative parent. Everything else flows in auto layout.

Constraints — pinned overlay children

Only for elements absolutely positioned inside a position:relative parent: status dot on an avatar, close button in a modal, today-line in the Gantt, toast stack in the viewport. The pinned edge stays put as the parent resizes. Never use constraints for flow layout.

Do
Hug controls, fill content, fix chrome — and always fix with a token (--rail-w, --bar-h), never a magic number.
Clamp every fill: pair flex: 1 with min-width: 0 so tables and long IDs can't blow the pane open.
Reserve constraints for overlay children — badge on avatar, close button, scrim (.pin-x.pin-y).
Don't
Don't fix widths on text-bearing elements — labels are translated and IDs grow; hug or clamp instead.
Don't use absolute positioning for flow layout — if it isn't floating over something, it belongs in auto layout.
Don't let a fill grow past its clamp — a 1600px-wide input on a wide monitor is a bug, not a feature.

Spacing & shrink floor

Two rules enforced across all 118 component source files this pass.

No hand-typed spacing
Every gap/padding/margin (and directional variants) reads a --space-* token, snapped to the nearest step on the scale — never a bare pixel number. Values under 4px (hairline/optical nudges, not layout spacing) are the one exception.
Shrinkable children get min-width:0
Any flex child with flex:"1 …" gets an explicit min-width:0 floor, so it can shrink inside a crowded toolbar row instead of forcing an overflow — the same fix .w-fill/.grow already apply as utility classes.
Max-width caps stay put
Existing caps (search boxes, popovers, summary cards) were left as-is — this pass didn't invent new ones. A component picks a container-query clamp or a viewport breakpoint based on where it actually sits, per the existing tokens above.
