Auto layout — the component contract

Every AgniUI component and pane is a flex auto-layout that declares eight properties. Siblings are spaced by gap tokens on the container — margins between siblings are banned. In code this is <Cluster> / <Stack> (or .al-h / .al-v); in Figma it's Auto layout with the same eight fields.

1 · Direction
flex-direction: row | column
Row = Cluster (toolbars, bars, meta rows). Column = Stack (forms, cards, panes).
2 · Gap
gap: var(--cluster-tight|default|loose)
Token only — 8 / 12 / 20, or --space-*, --pane-gap. Never sibling margins.
3 · Padding
padding: var(--pane-pad | --space-*)
The container owns its inset. Controls read density (--density-control-h).
4 · Alignment
align-items: center | stretch | baseline …
Cross axis. Rows default center (baseline for mixed type sizes); stacks default stretch.
5 · Distribution
justify-content: start | between | end …
Main axis. between for bars & card headers (title ↔ actions); otherwise start.
6 · Wrapping
flex-wrap: wrap | nowrap
Chips, filters & field grids wrap. Toolbars don't — overflow into a ⋯ menu instead.
7 · Overflow
overflow: auto (on the pane, not the page)
Panes & table bodies scroll within; bars and rail stay fixed. Tables scroll x when needed.
8 · Clip content
overflow: hidden + border-radius
Clip flush media inside cards/thumbnails. Never clip a container that spawns menus or popovers.

In code

// The contract is the props of Cluster (row) and Stack (column):
<Cluster gap="tight" justify="between" padding="0 var(--space-4)">…</Cluster>
<Stack gap={16} padding="var(--pane-pad)" overflow="scroll-y">…</Stack>
// Static HTML uses the utilities from tokens/layout.css:
<div class="al-h jc-between al-wrap" style="--gap: var(--space-2)">…</div>
Do
Space siblings with gap on the container; use padding for the inset — the two never substitute for each other.
Use baseline alignment when a row mixes type sizes (page title + record count).
Declare all eight fields when specing a new component — "unspecified" is how desks drift apart.
Don't
Don't add margins between siblings or space with <br>/empty divs — gap owns rhythm.
Don't hard-code px gaps — a gap that isn't a token won't follow density modes.
Don't clip a menu's parent or nest scrollbars — popovers escape via the z-scale; one scroll region per pane.
